# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The MediLink development team takes healthcare data privacy and patient confidentiality extremely seriously.

If you believe you have discovered a security vulnerability in MediLink, please do **NOT** open a public issue on GitHub. Instead, follow these steps:

1. Send an email to the security lead or repository maintainer with:
   - Type of vulnerability
   - Step-by-step instructions or Proof of Concept (PoC) to reproduce
   - Potential impact
2. You will receive an acknowledgment within 48 hours.
3. We will collaborate with you to validate the vulnerability and release a patch before public disclosure.

Thank you for helping keep healthcare data secure!
